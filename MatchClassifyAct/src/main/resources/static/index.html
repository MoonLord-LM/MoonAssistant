    左侧列表 = 每一种「汇总图算法」（全图交集六档（100% = 样本完全一致，另有 90/80/70/60/50%）、多数 / 均值 / 去重均值三族及 8×8·32×32 块图、各档独有区图、各分类的注意区交集图（以关注点为中心，未设 = 屏幕中心）与鼠标点击分类的点击区交集图（以点击点为中心），与识别参与比对的是同一套产物）。 验证方式：把每个分类的原图，按该算法生成的汇总图逐张与【全部分类】的同一算法汇总图逐点比对（口径与识别一致），统计五个评价指标——A = 生成成功率：能生成有效合成图（产物存在且非全透明）的分类占参与分类的比例；B = 自分类平均匹配值：分类包含的每张原图与「该分类的该算法生成图」比对的匹配占比均值（越高越好，表明样本比较集中）；C = 其它分类平均匹配值：其它分类的每张原图与「该分类的该算法生成图」比对的匹配占比均值（越低越好，表明该分类的产物不易被别的分类原图匹配）；D = 匹配正确率：在能生成有效图的分类里，原图与「所有分类的该算法生成图」匹配、最高分唯一最高且恰是自己分类的占比，越高越好；无法生成有效图的不参与统计，无法给出最高值的结果的也不参与统计（这些样本只计入 E，故 D 的分母 = 可匹配样本数 − 无法区分数）；E = 无法区分率：全部可匹配样本里，无法给出最高值的结果（最高匹配度被 ≥2 个分类并列，分值一样、分不出该选哪一类）的占比（越低越好；分母 = 全部可匹配样本，与 D 的分母不同）。

    算法调优 · 详细说明
    本视图把「特征验证」算出的 A/B/C/D/E 自动组合成匹配算法，再用权重 Y 调优；下面按「算法怎么来 → 怎么判定 → 打平怎么办 → 自动调整参数 → 缓存与过期」依次说明。
    算法调优建立在特征验证结果之上：先「汇总分析」生成各分类产物，再到「特征验证」算出每个特征的 A/B/C/D/E，本视图据此自动组合算法。
    每个特征的基础分 X = B 自分类平均匹配值 − C 其它分类平均匹配值（越大越能区分自己与其它分类），权重 Y ∈ [0,2] 默认 1 可改（步进 0.001，上下箭头 / 手输都按 0.001 收齐）。
    某分类匹配度 = Σ「(100 − 不匹配占比) × X × Y」÷ Σ「X × Y」（加权平均，只累加该分类有有效产物的特征），匹配度唯一最高的分类即判定结果，与样本归属分类一致即命中。
    打平（并列）处理：逐张样本先看每个特征——某特征的最高匹配值被 ≥2 个分类并列（分值一样、分不出该选哪一类）即视为该特征有问题，这张样本的加权平均里整张放弃该特征；放弃后重新加权，若最高匹配度仍然并列（或本张样本的可用特征被全部放弃、无从判定），则给出无法区分的最终结论：既不算命中也不算判错，单列「无法区分率」（分母 = 可判定样本、含无法区分，与特征验证的 E 同口径）；它也不进「匹配正确率」的分母（正确率 = 命中 /（可判定样本 − 无法区分）= 命中 /（命中 + 判错），与特征验证的 D 同口径），故正确率 + 无法区分率不一定等于 100%。
    自动调整参数（琥珀色按钮，位于本视图右上角）：先「验证所有算法」并等它跑完（结果要能对上当前样本 / 产物）才能点。它逐算法逐权重把 Y 分两轮各试 100 次（精确到 0.001）：第一轮在 0~2 之间整段随机，第二轮在第一轮定下来的值附近按 ±0.001 ~ ±0.1 就近微调；每个权重的试探次数 = 2 轮 × 100 次（5 个特征的算法即 5 × 2 × 100 = 1000 次评分，张数越多越慢）；每一轮都只要这次改动让该算法的匹配正确率上升或无法区分率下降就采纳（本轮 100 个候选里取「正确率更高、再比无法区分率更低」的那个，一轮都没改善就保持该轮起点），采纳后立即把当前权重写入 classify/opt-weights.json（可随时手删，删了回到默认全 1）；全部调完再用最终权重重算一遍全部算法，界面的权重框、结果卡与结论随新权重刷新。界面上的权重框也以这份文件为起点（改了文件刷新页面即生效）。
    单一特征算法只有一个特征，权重 Y 在 Σ「X × Y」里被约掉、改它对加权平均没有任何影响，因此权重固定 1、只展示数值不给编辑框（勾选框同样锁上）、也不参与「自动调整参数」（后端也不把它写进权重文件）。
    还没做「特征验证」时这里也会先列出全部算法（当前 4 个：单一最佳匹配特征 / 单一最佳+100%正确率特征 / 单一最佳+90+%正确率特征 / 单一最佳+80+%正确率特征）的空位，结果处显示未计算。
    缓存与过期：验证结果完整缓存到 summary/opt-result.json（各算法结果 + 逐分类明细 + 最近一次「自动调整参数」摘要），下次打开本页自动恢复上次结果 ——「已标注（classify/）、汇总分析（summary/ 产物）、特征验证（各特征的五种指标）三处数据都没变」就直接用上次的，不必重算；只要其中任何一处有变动（含特征验证被重算后特征口径变了），结果立即标记过期：右栏统计行给出提示、并提示一次重新计算，结论卡 / 权重卡里也会标黄说明。另外特征选择 + 权重数值每次跑完都会覆写一份最新的快照到 summary/opt-weights.json（每个算法：特征 kind 清单 + 基础分 X + 权重 Y + 当时指标），方便后续功能 / 开发验证直接读取，不必解析界面状态。
    本视图的比对矩阵与特征验证共用同一份缓存（summary/verify-matrix.json）：特征验证刚跑完就直接在内存里命中 —— 换一组权重、再来一次「验证所有算法」或「自动调整参数」都不必重新逐图比对；跨重启也按每张图的大小与修改时间复用没变过的部分，右栏统计行会给出复用规模。
    验证期间建议先停掉「特征验证」与执行模式自动识别（两者都会长时间占用 CPU 与磁盘 IO）。
