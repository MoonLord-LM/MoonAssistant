    算法调优 · 详细说明
    本视图把「特征验证」算出的 A/B/C/D/E 自动组合成匹配算法，再用权重 Y 调优；下面按「算法怎么来 → 怎么判定 → 打平怎么办 → 自动调整参数 → 缓存与过期」依次说明。
    算法调优建立在特征验证结果之上：先「汇总分析」生成各分类产物，再到「特征验证」算出每个特征的 A/B/C/D/E，本视图据此自动组合算法。
    右上角「刷新算法特征」= 按最新特征验证结果重新组合算法与特征（含基础分 X），再按当前权重 Y 重新计算全部算法的分类匹配正确率（没变过的部分直接复用逐图比对矩阵，不必重比）；改完权重 Y 会自动只重算被改动的那个算法，手动点它则是全部算法都重算。
    每个特征的基础分 X = B 自分类平均匹配值 − C 其它分类平均匹配值（越大越能区分自己与其它分类），权重 Y ∈ [0,10] 默认 1 可改（步进 0.001，上下箭头 / 手输都按 0.001 收齐）。改完（回车或点别处）会立刻锁住本视图的按钮与输入框、并按新权重自动重新验证一遍（把某个特征的 Y 改成 0 = 该特征不参与本算法，同样立刻重算），不必再点「刷新算法特征」；这轮只重算被改动的那个算法（其余算法直接沿用上次结果：同一批样本 / 产物 + 同一份比对矩阵 + 权重没变，数值必然一样），因此只有它的数值后面标 （等待刷新）、其余算法连卡片里的逐分类明细都不重建，跑完自动换成新值。（手动「刷新算法特征」= 全部算法都重算、都标；「自动调整参数」会改所有算法的权重，同样全标。）左栏每行右上角的状态 chip 同步这条状态：未计算 / 计算中… / 等待刷新 / 需重算 / 已计算（与「特征验证」「汇总分析」列表行同一套口径与配色），数值一律放在下一行。改权重触发的这轮重算，开始 / 结束各弹一条提示（同时写进右上角「历史日志」）：开始写「修改「<算法名>」的「<特征名>」权重 Y <旧值> -> <新值>，开始重新计算」，结束写「重新计算完成，匹配正确率/无法区分率的变化——「<算法名>」匹配正确率 <旧> -> <新>、无法区分率 <旧> -> <新>，用时 <N 秒>」（只列真的变了的算法）。
    某分类匹配度 = Σ「(100 − 不匹配占比) × X × Y」÷ Σ「X × Y」（加权平均，只累加该分类有有效产物的特征），匹配度唯一最高的分类即判定结果，与样本归属分类一致即命中。
    每个算法的结果卡横着并排三张：匹配正确率（含命中 / 判错 / 无法区分 / 跳过 / 用时）、无法区分率、生效特征 N / M——副文案：Y 权重值大于 0 的特征，视为生效特征，参与最终匹配值的计算；Y 权重等于 0 的不参与计算（另列出全部权重值）；三张卡下面接通栏的「查看各分类匹配正确率与无法区分率」折叠明细。
    打平（并列）处理：逐张样本先看每个特征——某特征的最高匹配值被 ≥2 个分类并列（分值一样、分不出该选哪一类）即视为该特征有问题，这张样本的加权平均里整张放弃该特征；放弃后重新加权，若最高匹配度仍然并列（或本张样本的可用特征被全部放弃、无从判定），则给出无法区分的最终结论：既不算命中也不算判错，单列「无法区分率」（分母 = 可判定样本、含无法区分，与特征验证的 E 同口径）；它也不进「匹配正确率」的分母（正确率 = 命中 /（可判定样本 − 无法区分）= 命中 /（命中 + 判错），与特征验证的 D 同口径），故正确率 + 无法区分率不一定等于 100%。
    自动调整参数（琥珀色按钮，位于本视图右上角）：先「刷新算法特征」并等它跑完（结果要能对上当前样本 / 产物）才能点。它逐个算法地走：每个算法先做 100 次随机组合尝试——每次随机取 1 ~ 全部 个特征，把它们各自的权重 Y 都随机取 0 ~ 10 内的任意值（其余特征保持当前值；一次能同时改动多个权重、随机范围更大，避免停在局部最优），只要这次尝试让该算法的两率有改善就立刻采纳、并成为后面尝试的起点；再逐个权重 → 逐个轮次地精调，每个可调权重第一遍 4 轮共 403 次（精确到 0.001）：第 1 轮 0~10 整段随机 100 个、第 2 轮 0.1 ~ 10 按 0.1 递增递进扫描 100 个、第 3 轮最优值微调 200 个（加法 100 个 + 减法 100 个，±0.001 ~ ±0.1 逐个走一遍）、第 4 轮四舍五入微调 3 档（0.01 / 0.1 / 1）（5 个特征的算法即 100 + 5 × 403 = 2115 次评分，张数越多越慢）；随机组合尝试与前三轮都只要这次改动让该算法的匹配正确率上升或无法区分率下降就采纳（本轮候选里取「正确率更高、再比无法区分率更低」的那个，一轮都没改善就保持该轮起点；第 4 轮四舍五入微调的判据是「两率一点没变」）；某个权重这一遍（上面四轮）里采纳过更好的值（第 4 轮不算），就再只跑随机轮重试（一遍 300 个 0~10 的随机值、精度 0.001，第 2~4 轮不再重复跑；最多追加 3 遍，进度行会显示「第 N 遍」；没找到改进的权重只跑一遍），采纳后立即把当前权重写入 classify/opt-weights.json（可随时手删，删了回到默认全 1）；全部调完再用最终权重重算一遍全部算法，界面的权重框与结果卡随新权重刷新（采纳几处 / 共试探多少权重 / 耗时 / 权重落盘路径由右栏统计行给出，不再单独占一张卡）。界面上的权重框也以这份文件为起点（改了文件刷新页面即生效）；「刷新算法特征」跑完也会把本次算过的权重写进同一份文件（只写这次算过的算法、值没变就不重写）——两份任务的权重都不会只留在内存里，重启后界面与后续功能读到的都是最近一次算过的值。第 4 轮四舍五入微调（逐权重）：把这个权重当前值依次按 0.01 → 0.1 → 1 四舍五入后各重算一遍，只要匹配正确率与无法区分率一点没变，就说明多出来的小数位对结果没有影响、直接换成更简单的值（例如 3.427 → 3.43 → 3.4 → 3，采纳后再拿新值试更粗的一档；两率一变就保留原值），最终权重更简单直白；被换过值的权重个数由右栏统计行交代。
    单一特征算法只有一个特征，权重 Y 在 Σ「X × Y」里被约掉、改它对加权平均没有任何影响，因此权重固定 1、只展示数值不给编辑框、也不参与「自动调整参数」（后端也不把它写进权重文件）。
    还没做「特征验证」时这里也会先列出全部算法（当前 5 个：单一最佳匹配特征 / 单一最佳+100%正确率特征 / 单一最佳+90+%正确率特征 / 单一最佳+80+%正确率特征 / 单一最佳+70+%正确率特征）的空位，结果处显示未计算。
    缓存与过期：验证结果完整缓存到 summary/opt-result.json（各算法结果 + 逐分类明细 + 最近一次「自动调整参数」摘要），下次打开本页自动恢复上次结果 ——「已标注（classify/）、汇总分析（summary/ 产物）、特征验证（各特征的五种指标）三处数据都没变」就直接用上次的，不必重算；只要其中任何一处有变动（含特征验证被重算后特征口径变了），结果立即标记过期 —— 像「汇总分析」那样：主图区顶部出现一条琥珀色「已过期 · 需重算」状态条，同时主图区算法卡片、左栏数值与结果卡照常显示上次的数据（只展示、不可改，权重框锁上），卡片标题标「（已过期）」、左栏状态 chip 标「需重算」、右栏统计行给出提示、并提示一次重新计算；状态条上的按钮按情况给「去特征验证」（特征验证结果已变旧、算法与特征要先按最新数据重新组合）或「重新计算」（能组合、只是结果旧）。另外特征选择 + 权重数值每次跑完都会覆写一份最新的快照到 summary/opt-weights.json（每个算法：特征 kind 清单 + 基础分 X + 权重 Y + 当时指标），方便后续功能 / 开发验证直接读取，不必解析界面状态。
    本视图的比对矩阵与特征验证共用同一份缓存（summary/verify-matrix.json）：特征验证刚跑完就直接在内存里命中 —— 换一组权重、再来一次「刷新算法特征」或「自动调整参数」都不必重新逐图比对；跨重启也按每张图的大小与修改时间复用没变过的部分，右栏统计行会给出复用规模。
    验证期间建议先停掉「特征验证」与执行模式自动识别（两者都会长时间占用 CPU 与磁盘 IO）。
