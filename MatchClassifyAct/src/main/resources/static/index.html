    调优目标 = 已标注样本五族加权命中自家分类占比（并列取安全边际更大者）。五族权重只作用于识别差异度： 差异度 = (A·w0 + B·w1 + C·w2 + D·w3 + E·w4) ÷ 参与族权重和；权重 0 = 整族不参与，数值越大该族影响越强。
    主图区可拖动权重族滑块后点「应用权重」即时看识别效果；「应用最优」把最近一次寻优的最优权重写入运行时并持久化（重启仍生效），「恢复默认」还原 50/15/10/10/15 并删除持久化文件。
