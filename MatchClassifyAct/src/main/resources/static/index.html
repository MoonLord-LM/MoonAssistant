    汇总图算法 · 自回归验证
    左侧列表 = 每一种「汇总图算法」（全图交集五档、多数 / 均值 / 去重均值三族及 8×8·32×32 块图、各档独有区图、点击动作分类的点击区交集图，与识别参与比对的是同一套产物）。 验证方式：把每个分类的原图，按该算法生成的汇总图逐张与【全部分类】的同一算法汇总图逐点比对（口径与识别一致），统计两个评价指标——A = 样本与「自分类汇总图」比对的不匹配占比均值（越小说明该算法生成的概括图越贴近本分类样本）；B = 样本在全部汇总图里匹配最好且正确匹配到所属分类的比例（越高说明区分度越好）。
    先从左侧选中一个算法查看它的评分与分类明细；或点右栏「开始验证」对全部算法顺序计算（样本较多时耗时较长，完成后结果自动缓存）。
    分类标注匹配动作样本数A · 自分类平均匹配值（越低越像）匹配正确分类的比例匹配正确分类的个数

    左侧选择分类标注查看对照图。

    特征验证

    尚未验证。
    A 自分类平均匹配值：每个原图与「自己分类的该算法汇总图」比对的不匹配像素占比，取全体样本平均（0~100，越低越好）。
    B 匹配正确分类的比例：每个原图在全部同类汇总图里匹配最好且恰好是自己分类的比例（0~100，越高越能区分开）。
    点左侧某个算法，右侧显示该算法的 A/B 汇总与每个分类的 A/B 明细。
